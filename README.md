# AAKDE Website

Frontend for AAKDE, a quantitative analytics firm.

## Tech
React (Vite), Tailwind CSS v4, GSAP ScrollTrigger, Lucide icons

## Run locally
npm install
npm run dev

## Highlights
- Scroll-driven hero that crops into a chart card (clip-path + ScrollTrigger)
- Reveal and parallax effects through `data-reveal` / `data-speed` attributes
- Dark/light theme switch via `data-theme` in `index.html`
- Validated contact form (frontend only)

Built with AI assistance, as permitted.
